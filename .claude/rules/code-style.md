# Стиль кода (обязательно)

- Ноль комментариев в исходниках, включая TODO и разделители. Нужен комментарий — переименуй/разбей.
- Никаких инлайн объектных типов: `function f(x: { a: number })` запрещено, заводи `interface`.
- Один класс на файл; классы не объявляются внутри функций и выражений.
- `enum`, `namespace`, parameter properties запрещены (`erasableSyntaxOnly`).
- Перечисления — `as const`-объект + одноимённый тип через `ValueOf`.
- Типы импортируются отдельной строкой `import type`.
- Имена: классы/интерфейсы/типы — PascalCase (без префикса `I`), константы-таблицы — UPPER_CASE,
  файлы с классом/интерфейсом — PascalCase, модули функций — camelCase.
- `switch` по объединению — исчерпывающий; в `default` — `assertNever`, если ветки не все.
- Не плодить дублирование: общая логика клиента и сервера — в `packages/shared/src/rules`.
- Без optional chaining (`?.`): явная проверка, ранний `return`, Null-объект. Ловит линтер.
- Строка ≤ 100 символов; длинные строки текста — конкатенацией.
- Текст для игрока — только в `client/src/i18n/locales/{ru,en}.ts`, числа — из конфига.
- Общие помощники уже есть: `nearestTo`, `directionTo`, `cellCenter`/`cellAt`, `hasBit`,
  `fractionOf`, `lerpPoint`. Не пиши их заново.
- Перед завершением задачи: `pnpm check`.
