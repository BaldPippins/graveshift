# Неткод (обязательно)

- Движение игрока (и прыжок) меняется только через `stepPlayerMotion` — иначе разъедется
  предсказание.
- Всё, что клиент предсказывает, должно квантоваться так же, как в протоколе (`roundTrip*`).
- Снапшот кодируется один раз на тик и рассылается всем; персональное — отдельными сообщениями.
- Хитскан идёт через `HitscanResolver` с `viewTick` (лаг-компенсация), не напрямую по текущим позициям.
- Случайность в симуляции — только `world.random` (`SeededRandom`).
- Входящие байты недоверенные: читать через `BinaryReader` (`oneOf`, лимиты, `expectEnd`).
- Горячие циклы (тик, кадр) без лишних аллокаций: переиспользуй `Vec2`, пулы, `RingBuffer`.
- Личность игрока — `ClientSession`, сокет — `ClientConnection`; id игрока не привязан к сокету.
- Любой таймер/подписка на соединение снимается при закрытии; проверяй тестами на обрывы.
- Подробности: `docs/netcode.md`.
