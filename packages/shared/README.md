# @graveshift/shared

Платформенно-независимое ядро, общее для сервера и клиента: без DOM, Node, three и ws.

| Модуль      | Что внутри                                                                       |
| ----------- | -------------------------------------------------------------------------------- |
| `core/`     | векторная математика, `nearestTo`, `SeededRandom`, шина событий, кольцевой буфер |
| `config/`   | данные баланса: герои, враги, оружие, апгрейды, волны, торговец, сеть            |
| `model/`    | доменные перечисления и DTO                                                      |
| `rules/`    | чистые правила: движение, лавка и апгрейды, торговец, волны, проверка ника       |
| `world/`    | тайловая карта, `FlowField`, коллизии круг-сетка, рейкаст                        |
| `protocol/` | сообщения, игровые события, бинарный кодек с квантованием                        |

Сборки нет: пакет экспортирует исходники `.ts` (см. `exports` в `package.json`).
Изменил протокол — подними `NETWORK.protocolVersion` в `config/simulation.ts`.
