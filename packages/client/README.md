# @graveshift/client

Браузерный клиент: Vite + three.js + Preact. Работает с мышью и клавиатурой и с тачем.

```bash
pnpm --filter @graveshift/client dev       # http://localhost:5173, прокси /ws и /api на сервер
pnpm --filter @graveshift/client build     # сборка в dist/, её раздаёт сервер в проде
pnpm --filter @graveshift/client preview   # посмотреть собранную версию
```

Порт сервера для прокси — `GRAVESHIFT_SERVER_PORT` (по умолчанию `8686`).

## Слои

| Папка      | Ответственность                                                           |
| ---------- | ------------------------------------------------------------------------- |
| `net/`     | WebSocket-клиент и шина входящих сообщений                                |
| `game/`    | часы сервера, буфер снапшотов, интерполяция, предсказание, шина событий   |
| `input/`   | клавиатура/мышь, виртуальные стики, блокировка системных жестов, привязки |
| `meta/`    | настройки, хранилище, счётчики статистики и ачивки                        |
| `i18n/`    | словари `ru`/`en` с общим типом `Messages`, определение языка             |
| `content/` | данные представления: модели оружия, цвета, иконки                        |
| `assets/`  | манифест моделей Kenney (оружие подхватывается из `weaponContent`)        |
| `render/`  | three.js: сцена, карта, персонажи, удары и ярость, эффекты, камера        |
| `ui/`      | Preact-экраны и HUD                                                       |
| `app/`     | склейка: `AppController`, соединение и возврат после обрыва, состояние UI |

## Управление

ПК: WASD, мышь, ЛКМ — огонь, ПКМ — удар, пробел — прыжок, B — лавка (у надгробия — оживить
торговца). Телефон: левый стик — движение, правый — прицел, за пунктирным кругом — огонь 🔥;
кнопки удара, прыжка, перезарядки и смены ствола; табличку торговца можно нажать. Подробнее —
[docs/gameplay.md](../../docs/gameplay.md).

## Тексты и языки

Весь текст интерфейса — в `src/i18n/locales/ru.ts` и `src/i18n/locales/en.ts`, оба типизированы интерфейсом
`Messages`: новый ключ без перевода не скомпилируется. Числа баланса в тексты подставляются из
конфига. Язык выбирается автоматически по браузеру и переключается в главном меню и настройках.
